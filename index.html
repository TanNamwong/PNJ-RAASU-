ติดตั้ง PNJ-RAASU

เลือกคำแนะนำให้ตรงกับอุปกรณ์ของคุณ

Android · Chrome

  1. เปิดเว็บไซต์ PNJ-RAASU ผ่าน Chrome
  2. แตะเมนู ⋮ มุมขวาบน
  3. เลือก “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก”
  4. ยืนยันการติดตั้ง

iPhone / iPad · Safari

  1. เปิดเว็บไซต์ผ่าน Safari
  2. แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น)
  3. เลือก “เพิ่มไปยังหน้าจอโฮม”
  4. แตะ “เพิ่ม”

iOS ไม่อนุญาตให้เว็บไซต์สั่งติดตั้งอัตโนมัติ ต้องเพิ่มผ่านเมนูแชร์

การติดตั้ง PWA ต้องเปิดผ่าน HTTPS เช่น GitHub Pages และไม่สามารถติดตั้งจากหน้า preview หรือไฟล์ในเครื่องโดยตรงได้
