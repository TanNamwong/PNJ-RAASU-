# PNJ-RAASU — PWA

ชุดไฟล์เว็บแอปสำหรับ GitHub Pages รองรับ Android และ iOS (เพิ่มลงหน้าจอโฮม)

## อัปโหลดขึ้น GitHub
1. สร้าง repository ชื่อ `PNJ-RAASU`
2. แตก ZIP แล้วอัปโหลดไฟล์/โฟลเดอร์ทั้งหมดในโฟลเดอร์ `PNJ-RAASU` ไปไว้ที่ root ของ repository
3. ไปที่ Settings → Pages
4. เลือก Deploy from a branch → `main` → `/ (root)` แล้ว Save
5. รอ GitHub Pages เผยแพร่ จากนั้นเปิด URL ด้วย HTTPS

## ติดตั้ง
- Android: เปิด URL ด้วย Chrome → เมนู ⋮ → Install app / Add to Home screen
- iPhone/iPad: เปิด URL ด้วย Safari → Share → Add to Home Screen

## วิธีเผยแพร่อัปเดต
1. แก้ไขไฟล์แอปตามต้องการ
2. รันสคริปต์ซิงก์เวอร์ชันให้ครบทุกไฟล์ในคำสั่งเดียว:
   `./bump-version.sh 1.0.3 "รายละเอียดอัปเดต"`
   (แก้ `version.json`, `APP_VERSION` ใน `index.html` และ `VERSION` ใน `sw.js` พร้อมกัน ชื่อแคชเปลี่ยนตามเวอร์ชันอัตโนมัติ)
3. Commit/Push ขึ้น GitHub Pages
4. แอปจะตรวจสอบเวอร์ชันเมื่อเปิดแอป/กลับมาใช้งาน และตรวจซ้ำเป็นระยะขณะเปิดแอป
   ผู้ใช้กด “อัปเดตตอนนี้” แล้วแอปจะโหลดไฟล์ใหม่และเปิดใหม่เอง

## ข้อจำกัดแพลตฟอร์ม
- iOS ไม่รองรับ prompt ติดตั้งจากเว็บไซต์ ต้องให้ผู้ใช้กด Share → Add to Home Screen เอง
- การแจ้งเตือนอัปเดตในชุดนี้เป็นการแจ้งในแอปขณะเปิดใช้งาน ไม่ใช่ Push Notification ตอนแอปปิด
- Push Notification จริงต้องมี Push Server, การสมัครรับ push และการตั้งค่าฝั่งเซิร์ฟเวอร์เพิ่มเติม
- PWA ไม่สามารถบังคับอัปเดตโดยไม่ให้ผู้ใช้ยืนยันได้

## สิ่งที่แก้ในเวอร์ชัน 1.0.2
- แก้หน้าเว็บรีโหลดเองหนึ่งครั้งตอนเปิดครั้งแรก (controllerchange)
- แก้ป๊อปอัปอัปเดตที่อาจ error เมื่อถูกเรียกซ้ำ และเทียบเวอร์ชันแบบตัวเลข
- แก้แคชของ GitHub Pages ที่ทำให้ติดอัปเดตวนซ้ำ (ใช้ no-cache / reload ใน Service Worker)
- ชื่อแคชผูกกับเวอร์ชันอัตโนมัติ และไฟล์อื่นใช้ stale-while-revalidate
- เพิ่มไอคอน maskable (Android) และ apple-touch-icon 180px + meta สำหรับ iOS
- เพิ่ม `404.html` และสคริปต์ `bump-version.sh`
- ทดสอบแล้ว: ติดตั้ง Service Worker, ใช้งานออฟไลน์, ทุกแท็บ, การแจ้งอัปเดต, ทำงานใน sub-path ของ GitHub Pages
